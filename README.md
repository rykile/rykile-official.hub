# RYK!LE Official Profile & Links — Prototype

A public-facing profile/links page, separate from the Artist site.

## Included
- Lavender `#DDD2EF` base background
- Faint, tilted No Lose artwork layers that drift with scrolling
- Artist Icon and profile-first layout
- Image-like hyperlink cards for Instagram, YouTube, and Spotify
- Japanese / English toggle and responsive mobile layout

## Before publishing
Replace the generic Instagram, YouTube, and Spotify destination URLs in `index.html` with RYK!LE's official profile URLs. Add the Artist-site URL if desired.

Open `index.html` in a browser to preview.
