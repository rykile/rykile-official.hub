# RYK!LE — Scroll-reactive website prototype

A lightweight static prototype for GitHub Pages. The base background is `#DDD2EF`; the canvas dot/particle field responds to scroll position, with colors inspired by the supplied No Lose artwork. Includes Japanese/English toggle and the supplied artist portrait and cover image.

## Preview locally
Open `index.html` in a modern browser. No build step or external library is required.

## Publish to GitHub Pages
Upload the contents of this folder to the root of your repository. Keep `assets/` alongside `index.html`.

## Before publishing
- Replace placeholder Music / Instagram / YouTube links with official URLs.
- Confirm the bio and wording.
- Test on mobile and desktop.

The animation respects `prefers-reduced-motion` and caps the particle count for performance.
